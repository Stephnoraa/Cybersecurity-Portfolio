# Human Factors Security Awareness & WCAG 2.1 Accessibility Audit
**Core Focus:** Human Risk Management & Accessibility
## Tools & Technologies:
- VIVIDA Reels Platform
- WAVE Evaluation Tool
- Fezzant Extension
- WCAG 2.1 AA Standards.
## Key Scope:
- Researched primary human-factor threats (misconfigurations, overly permissive access, insider threats, awareness gaps) and analyzed the 2021 Meta global outage case study.
- Produced custom security training video modules on Insider Threats.
- Conducted WCAG 2.1 AA accessibility audits using WAVE and Fezzant tools, identifying screen reader and ARIA landmark gaps.
